# dbt-проект "Анализ смартфонов" (hw1)

Учебный проект для курса Data Engineer.  
Построение аналитических витрин на основе данных о характеристиках смартфонов.

---

## Задача

- Загрузить сырые данные из CSV в PostgreSQL.
- Создать трёхслойную архитектуру dbt:
  - **Staging** – первичная очистка и отбор полей.
  - **Intermediate** – агрегация уникальных комбинаций процессора и аккумулятора.
  - **Marts** – финальные витрины: топ-10 комбинаций и топ-10 брендов процессоров.
- Автоматизировать трансформации с помощью dbt.
